# Chocolate Sales Performance Dashboard | Power BI

## Overview

Interactive Power BI dashboard analyzing chocolate sales performance across time, markets, salespeople and products.

## Tools

- Power BI
- Power Query
- DAX

## Key Metrics

- Total Revenue: **$27.99M**
- Boxes Sold: **2M**
- Period: **Jan 2023 – Sep 2024**

## Dashboard Analysis

- Monthly revenue trends
- Market performance
- Salesperson revenue ranking
- Product performance
- Interactive date filtering
- KPI cards and visual analysis

## Key Insights

- UK and USA are among the strongest markets.
- Revenue shows noticeable month-to-month fluctuations.
- A smaller group of products contributes a significant share of revenue.
- Revenue performance varies across salespeople.
